# Private pre-1.0 preview

This is a private pre-1.0 preview.

Supported hosts:

- macOS 26 on Apple Silicon and Intel uses the same universal app.
- Windows Server 2025 x64.
- Ubuntu 24.04 x64 for AppImage and DEB packages.
- openSUSE Leap 15.6 x64 for RPM packages.

Close the app before installation. Install or replace the app manually.

Export your JSON files before a later pre-1.0 upgrade. Version `v0.1.0` does not need a local-state reset.

The app has no runtime update check.

GitHub-generated notes follow this preface.
